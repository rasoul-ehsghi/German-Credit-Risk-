This repository contains a Jupyter Notebook that analyzes the **German Credit Risk** dataset. The goal is to transform a symbolic dataset into a readable format and perform an initial credit risk analysis.

---

## 📌 About the Dataset

The original dataset contains **1,000 entries** with **20 symbolic/categorical features**, where each row represents a person applying for credit. Each person is labeled as a **good** or **bad** credit risk. The dataset was curated by **Prof. Hofmann**.

🔗 [Dataset on Kaggle](https://www.kaggle.com/datasets/uciml/german-credit/data)  
📚 Source: UCI Machine Learning Repository

---

## 🔍 Context & Purpose

The symbolic encoding of the original dataset makes it difficult to interpret. This project includes:

- 🔄 A Python-based transformation into a readable CSV format  
- 📉 Exploratory data analysis on selected relevant features  
- 📌 Credit risk factor identification  

---

## 📊 Selected Features

| Feature            | Description |
|--------------------|-------------|
| `Age`              | Numeric age of applicant |
| `Sex`              | Male or Female |
| `Job`              | 0: unskilled/non-resident, 1: unskilled/resident, 2: skilled, 3: highly skilled |
| `Housing`          | own, rent, or free |
| `Saving accounts`  | little, moderate, quite rich, rich |
| `Checking account` | Balance in DM |
| `Credit amount`    | Amount requested in DM |
| `Duration`         | Credit duration (in months) |
| `Purpose`          | car, furniture, radio/TV, business, education, etc. |
